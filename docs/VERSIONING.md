# Versioning

The pack uses semantic versioning with pre-release identifiers during the pilot period.

Examples:

- `v0.1.0-alpha.1` — first architecture checkpoint.
- `v0.2.0-alpha.1` — installer development line.
- `v1.0.0` — first stable release after repeatable installation, scanner normalization, fixtures, and real-repository pilot validation.

Target repositories record the installed pack version in `.security/copilot-pack.yml`.
