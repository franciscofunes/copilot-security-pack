# v0.2.0 Plan — Versioned Installer

The v0.2.0 milestone turns the repository from a reusable collection of files into a safely distributable VS Code Copilot security pack.

## Release objective

A user with a clone of `copilot-security-pack` can install or upgrade the pack in another Git repository with one PowerShell command, producing a reviewable Git diff and preserving repository-owned configuration.

## Acceptance criteria

- `installer/install.ps1` supports first installation and `-WhatIf` preview.
- Installation detects .NET and Angular/Yarn and installs only applicable components.
- Existing `.github/copilot-instructions.md` is never overwritten.
- Repository-owned policy, baseline, and exception files are create-if-missing only.
- Pack-managed files can be reconciled safely on repeated runs.
- `.security/copilot-pack.yml` records installed version and feature detection.
- `installer/upgrade.ps1` refuses accidental downgrades.
- Smoke tests prove installation into a representative .NET + Angular/Yarn fixture and a second idempotent installation.
- Copilot CLI, MCP, plugin marketplace, and Git submodules are not required.

## Still planned in this milestone

- Record pack-managed checksums in target metadata so upgrades can detect local edits before replacing managed files.
- Add uninstall/rollback behavior that never touches unrelated application files.
- Add .NET-only and Angular-only installer fixtures.
- Add installer conflict tests.
- Reorganize canonical distributable content under a dedicated `pack/` source tree once the installer contract is stable.
- Update README and changelog for the v0.2 distribution flow.

## Out of scope for v0.2

Full per-vulnerability NuGet/Yarn normalization and mature baseline fingerprinting remain the primary v0.3 work unless required by installer testing.
